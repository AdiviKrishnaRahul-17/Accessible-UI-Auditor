# Accessible-UI-Auditor
Accessible UI Auditor is a web-based tool that analyzes HTML code to detect accessibility issues. Using the axe-core and standards from Web Content Accessibility Guidelines, it identifies problems like missing alt text, poor contrast, and navigation issues, generates reports, and provides suggestions to improve website accessibility.
# Accessible UI Auditor

A tool that checks websites for accessibility issues and suggests improvements.

## Features
- Detects missing alt text in images
- Checks color contrast
- Finds accessibility errors in HTML
- Gives suggestions to improve UI accessibility

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project
2. Open index.html in browser
